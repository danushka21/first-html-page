Responsive Navbar
with CSS-Only Toggle

Horizontal links on desktop. Hamburger menu on mobile. Zero JavaScript — pure CSS checkbox hack with smooth animations.

✅ No JavaScript ✅ Flexbox ✅ Media Queries ✅ Checkbox Hack ✅ Accessible

How the CSS Checkbox Hack Works

  • A hidden <input type="checkbox"> is placed in the HTML
  • The hamburger icon is a <label for="menu-toggle"> — clicking it toggles the checkbox state
  • CSS sibling selector #menu-toggle:checked ~ .nav-links slides the menu in when checked
  • The 3 bars animate into an ✕ using transform: rotate() on :checked state
  • On desktop (>768px), the hamburger is hidden and links display as a flex row normally
