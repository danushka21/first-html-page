HTML

From Wikipedia, the free encyclopedia

HyperText Markup Language, commonly known as HTML, is the standard markup language used to create web pages. It is used to structure content on the World Wide Web using elements such as headings, paragraphs, links, images, lists, tables, and forms.

Overview

HTML describes the structure of a web page. A browser reads HTML documents and displays them as visible pages. HTML does not perform programming logic; instead, it organizes content using tags and elements.

HTML is usually used together with CSS and JavaScript. CSS controls the appearance of a web page, while JavaScript adds interactivity.

History

HTML was created in the early 1990s by Tim Berners-Lee. It was developed as a way to share documents through hyperlinks on the internet.

Development

Over time, HTML went through many versions. HTML5 introduced modern features such as audio, video, semantic tags, and improved support for web applications.

Markup

HTML markup is made up of elements. Most elements have an opening tag, content, and a closing tag. 

<p>This is a paragraph.</p>

Some elements, such as images and line breaks, do not require closing tags.

Elements

Common HTML elements include:

  • Heading tags - used for titles and section headings
  • Paragraph tags - used for text content
  • Anchor tags - used for links
  • Image tags - used to display images
  • List tags - used to create ordered and unordered lists
  • Table tags - used to display tabular data

Basic HTML Document Structure

Part Purpose
DOCTYPE Defines the document type
html Root element of the page
head Contains page information
body Contains visible page content

Example

A simple HTML page may contain headings, paragraphs, and links.

<!DOCTYPE html>
<html>
<head>
    <title>Sample Page</title>
</head>
<body>
    <h1>My Web Page</h1>
    <p>This is a paragraph.</p>
</body>
</html>
