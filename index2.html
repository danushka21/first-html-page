1. nav Tag

The nav tag is used to define navigation links in a webpage.

When to use: Use it for menus, page links, or website navigation bars.

2. main Tag

The main tag represents the main content of a webpage.

When to use: Use it once per page to hold the primary content.

3. section Tag

The section tag groups related content into separate sections.

When to use: Use it for topics like introduction, services, contact, or chapters.

4. article Tag

The article tag is used for independent content that can stand alone.

When to use: Use it for blog posts, news articles, reviews, or forum posts.

5. aside Tag

The aside tag contains extra information related to the main content.

When to use: Use it for sidebars, tips, ads, related links, or additional notes.

6. header Tag

The header tag defines the introductory part of a webpage or section.

When to use: Use it for page titles, logos, headings, and intro content.

7. footer Tag

The footer tag defines the bottom section of a webpage or content block.

When to use: Use it for copyright, contact details, author info, or useful links.

8. figure Tag

The figure tag is used for images, diagrams, or illustrations with captions.

When to use: Use it when an image or diagram needs a caption.

9. time Tag

The time tag represents a specific date or time in a machine-readable format.

Example: 5 May 2026

When to use: Use it for dates, deadlines, event times, or published dates.

10. mark Tag

The mark tag highlights important text.

Example: HTML semantic tags make a webpage more meaningful and structured.

When to use: Use it to highlight keywords or important parts of content.
